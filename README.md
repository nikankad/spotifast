# Spotifast PR review evidence

Native before/after captures and Linux validation results for the Play next and enlarged cover contributions.

Download this branch as a ZIP, extract it, and open `reviews/index.html` in your browser. The comparison offers light/dark themes, normal/narrow windows, interaction states, Before/After buttons, and a selector for the two contributions.

Baseline: `dd2d5e34e66d4e01e31e595a3022a1de808b449a`. Candidate commit IDs and check results are in `validation.json`. Captures use demo data and cached placeholder images on Debian 13 with X11/Xvfb and software OpenGL. macOS, Windows and live Spotify playback remain to be checked.
