Play next

A new Play next entry inserts the chosen songs before the existing manual queue during local playback. The current song keeps playing. Other devices show a disabled entry.

Actual native Linux captures (Debian 13, X11/Xvfb, software OpenGL). Baseline: upstream dd2d5e3. Candidate: feat/play-next (7fb4730). Same demo data, page, click and window size in each pair. PR #841. macOS and Windows captures remain to be checked.
